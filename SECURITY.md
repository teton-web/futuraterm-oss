# Security

Report vulnerabilities privately via [GitHub Security Advisories](https://github.com/teton-web/futuraterm-oss/security/advisories/new) on the public snapshot.

Do not open a public issue for bugs that could expose user data, credentials, or unauthenticated access.

The marketing site (`website/`) lives only on private `teton-web/futuraterm`; report site/auth issues through that repo’s advisories, not here.
